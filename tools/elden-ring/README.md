# エルデンリング ビルド構築ヘルパー

公開ファイルは `apps/elden-ring-build-helper.html`。約2.2MBの単一HTMLに計算データ・ロジック・UIを内蔵し、外部APIへの入力送信や実行時のデータ取得を行わない。Appsの自動登録用manifestを含む。

## 利用できる機能

- 8能力値、素性、片手／両手、通常・喪色強化。
- 武器488件（素手含む）・派生3,296件の必要能力、AR、属性内訳、状態異常蓄積、触媒補正。
- 日本語／英語検索、武器種・派生・DLCフラグ、装備可能フィルター、最良派生、最大6件比較、能力値+1のAR増分。
- 通常攻撃86プロファイルの理論連続DPSと対敵DPS（未実測）。590派生／持ち方に対応し、未対応理由・各段の内訳を表示。DPSの選択は保存・共有に対応。
- 武器詳細の5能力別ダメージ推移（単一グラフに重ねた5系列・色別凡例と表示切替・共通縦軸・要求不足の破線・現在との差・+1増分）。選択攻撃成分と対敵条件に連動し、1〜99／仮想1〜148を切り替え。装備補正後の能力値を直接比較し、ゲーム内の割り振りは99まで。
- 魔術84・祈祷129の要求値・記憶枠、523派生成分の係数、触媒の自動比較、単一成分威力／FP効率。
- 武器6スロット、防具722件、タリスマン154件、常時能力・HP／FP・重量補正、基本カット率、ローリング、素性比較。
- 敵3,254プロファイル×NG〜NG+7、敵名／場所検索、耐性、防御式による推定、武器モーション別の個別ヒット計算。
- 敵名670種類を日本語表示。ボス区分、武器違い、形態、外殻破壊後の区別を保持し、日本語／英語どちらでも検索可能。敵の場所は元資料の英語表記。
- 影樹の加護と手動の攻撃力倍率。
- 記憶魔法、名前付き保存30件、JSON入出力、日本語名を含む共有URL、自動保存、別タブの変更検出と上書き防止。
- 既定戦技と戦灰116件の参考カタログ。カテゴリフラグを表示するが、完全な装着可否・戦技威力は未計算。

## ビルドを試すためのUI

- 装備先の選択画面で、交換前後の武器AR・総重量・ローリング区分・要求能力不足を表示。選択を確定するまで現在のビルドは変更しない。
- 中量以下を維持できる追加重量と、中量に戻すための減量を0.1刻みで表示。70%ちょうどは重量として扱い、装備による最大重量補正も反映する。
- 任意の目標レベル（1〜713）と残りポイント／超過を表示。目標は名前付き保存、共有URL、JSONに含め、旧ビルドでは未指定として読み込む。
- 保存ビルド同士、または現在のビルドとのA/B比較。配分能力値、HP・FP・スタミナ、強靭、重量、ローリング、主武器AR、全スロットの装備差を表示。数値差はB−A。各ビルドの装備補正・強化・持ち方で計算する。
- 武器のお気に入りは派生を横断して扱い、比較候補とは別の端末内保存にする。お気に入りのみの絞り込みと別タブの変更反映に対応。ビルド共有・取り消しには含めない。
- 魔法を1枚のカードにまとめ、比較する成分を選択。選択成分のFP・威力・触媒と順位を更新する。成分名は元資料の英名を表示し、成分間の合算はしない。成分選択は画面内の状態で、共有には含めない。
- 能力値・装備・計算条件・ビルド読込の直近20操作を取り消し／やり直し。名前の編集、お気に入り、保存一覧の削除は対象外。履歴は現在のタブ内だけで保持し、別タブとの保存競合中は操作を停止する。

## 計算の境界

武器のdecode・補正式はThomasJClarkのMITコードを移植。元の著作権表示・ライセンス全文をデータに収録し、アプリ内の出典にも表示する。ARは属性別値の合計であり、敵へのダメージやDPSとは異なる。

魔法ランキングは派生成分1つの防御前威力。通常、溜め、弾、爆発、自己蓄積などを合算しない。系統強化、条件付き攻撃効果、連続詠唱、全段命中、魔法・戦技DPS、PvP、部位、カウンター、敵の追加人数補正は未対応。補助・回復の威力は未計算として表示する。触媒の自動選択も系統強化を除く成分威力に限る。

効果表の常時能力値・HP／FP・重量・基本カット率は反映し、条件付き数値は反映しない。効果説明を表示するが、全効果を自動適用したことにはならない。防具の打撃・斬撃・刺突個別カット率は合成表示では省略。武器固有の能力値上昇や大ルーン・霊薬は自動適用しない。

敵への推定はBuild Planner「Damage Calc」N19の防御式を、属性・ヒットごとに適用する。元資料の条件付きモーション値、複合物理属性は未計算とする。加護・手動倍率は防御前攻撃力に適用する。最終ダメージに直接掛かるバフを手動倍率で代用しないこと。

武器・フレーム資料は1.17、参考シートは1.17.1表記。全パラメータ差分および実機の最終ダメージは未検証。日本語名は古いテキストも利用し、武器8件・防具18件は英名表示。DLCフラグは元資料の分類であり、現行の入手条件を保証しない。素性12件はPlannerの収録値で、追加2件は英名表示。

## 保守

```bash
node tools/build-elden-ring.mjs
node tools/test-elden-ring.cjs
```

- `engine.js`：純粋な計算・装備合成・入力検証。
- `ui.js`：画面・フィルター・保存・共有。
- `template.html`：HTML構造・レスポンシブCSS。
- `../../data/elden-ring-payload.json`：圧縮した計算用データと展開後SHA-256。
- `fixtures.json`：元のMITコードから生成した324件の数値期待値。

データ更新には別途保存した `elden-ring-implementation-data.zip` の展開フォルダを使用する。原本・ワークブック一式を公開リポジトリにコピーしない。

```bash
python3 tools/elden-ring/compile-data.py --source-dir /path/to/elden-ring-data
node tools/build-elden-ring.mjs
```

`compile-data.py`は標準ライブラリのみで、必要な数値・名称・効果説明を取り込み、再現可能なgzipとハッシュを生成する。元資料のURL・ハッシュも内蔵する。

## 検証

324件の期待値には能力不足、複合属性、触媒、状態異常、強化、両手持ちと99を超える実効筋力を含む。収集済みの元コードで全派生を照合する場合（Node 24以上のTypeScript strip対応が必要）：

```bash
ER_REFERENCE_DIR=/path/to/elden-ring-data/raw/weapon-calculator node tools/test-elden-ring.cjs
```

3,296派生×4条件＝13,184ケースの武器数値を照合し、`fixtures.json`を再生成する。元コードとの一致は移植の確認であり、独立した実機精度の保証ではない。

画面テストはPlaywrightを使う。

```bash
npm install --no-save playwright
npx playwright install chromium
node tools/test-elden-ring-ui.cjs
```

テストは一時HTTPサーバーを起動する。既存サーバーを使う場合は`ER_UI_URL`を指定する。ブラウザ実体を指定する場合は `ER_CHROME_PATH=/path/to/chrome`。`ER_BROWSER=webkit`でWebKitも実行できる。390px・1440px、検索、装備、敵、記憶、共有、JSON、再読込、オフライン単体起動を確認する。実機iOS Safari、文字拡大、支援技術は別途確認する。

追加UIの検証：

```bash
node tools/test-elden-ring-planning.cjs
node tools/test-elden-ring-workshop-ui.cjs
```

重量の境界6,400ケース、交換プレビュー、目標レベルの旧形式互換、取り消し・やり直し・履歴上限、独立したお気に入り保存と保存失敗、魔法の成分切替、A/Bの差、別タブ競合を確認する。管理環境で`file://`が制限される場合、既存画面テストは`ER_OFFLINE_HTTP=1`で単一HTMLのみを供給して通信遮断時の起動を確認できる。

Apps登録器 `node tools/build-register.mjs` はmanifestを読んで一覧に追加する。`apps.json`は手編集せず、mainへのマージ後の既存Actionsに生成を任せる。

## 理論DPSの実装

武器一覧に防御前と対敵のDPSソートを追加。`dps/runtime.mjs`が候補スナップショットと周期sidecarのハッシュを照合し、限定した通常攻撃モデルをHTMLに内蔵する。モデルの数値は実測済みと扱わず、画面で「理論・未実測」と明示する。各ヒットにMVと敵防御を適用してから周期合計を取り、発症ダメージ・条件付き攻撃効果・回復時間・ヒットストップは含めない。魔法・戦技DPSは未対応。計算の詳細は `dps/IMPLEMENTATION.md`。

```bash
node tools/test-elden-ring-dps.cjs
```

## 敵名の日本語表示

`enemy-names-ja.json` は元資料の敵名と日本語表示名の完全一致辞書。
名称以外の ID・周回・数値・英語の原名は変更しない。選択肢、敵詳細、対敵ランキング、武器詳細で共通利用する。
再ビルド時に全敵レコードの辞書網羅を検証し、未翻訳の名称が追加されたらビルドを停止する。

本編の固有名は [elden-ring-data/msg](https://github.com/elden-ring-data/msg/tree/4bbba478e478e9018d0293e0b18cd8cf706199e9) の英語・日本語 `item.msgbnd.dcx.json` 内 `NpcName.fmg` を同一 ID で照合。
DLC名は [ボス一覧](https://gamewith.jp/eldenring/320528) 等で照合し、通常敵の説明名・元資料独自の区分はアプリ用の訳を付ける。すべての説明名が公式名称という意味ではない。
元資料の `[Boss]`、`[Boss HP]`、武器、形態、破壊後の条件も保持する。
詳細には照合用の英語原名を併記し、日本語・英語双方の検索に対応する。
