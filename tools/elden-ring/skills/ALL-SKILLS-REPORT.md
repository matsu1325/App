## 採用したデータ

`SwordArtsParam`の全原値、日英名、戦灰ID、既定武器ID、L2/R1/R2のFPを保持した。FPの`-1`は原値として残し、正規化した値はnullにする。構え・追撃・連打などを合算した行動全体のFPは未確定。

判定窓の時間範囲、元イベント、武器別候補、Behavior→攻撃/弾/効果の接続、属性別MV・固定攻撃値、スタミナ・強靭削り・状態異常・各種フラグを保持した。弾の子弾・爆発・再命中・共有命中リスト、効果の置換・周期・攻撃時発生、持続・重複グループを追跡した。武器派生、強化、属性補正、補正曲線も別ノードとして接続する。装備の見た目・音・予約領域は抽出対象から除く。

バフ名と戦技名の一致は発見用の候補に留める。例えばデターミネーション1691の対敵倍率1.6と王騎士の決意1701の1.8、両者の持続原値10秒は取得できたが、発動・消費・対象・重複規則の完全解決を示すものではない。対プレイヤー倍率は別値として保持した。

## 照合結果

- 加工攻撃の属性別MVと固定攻撃値は、それぞれ3,337バリアントで原パラメータと一致。25件は対応するダメージパラメータがなく、効果のみ/プレースホルダー等の確認対象として残した。
- MV参考シートと3,176件一致。186件は該当行なし。不一致0件。ただし同じゲームデータに由来する資料の一致は、独立した実機検証ではない。
- 第1弾の4戦技・6入力のFP、通常/FP不足版12攻撃係数を回帰確認した。
- 16単体テストと、生成物のハッシュ・参照閉包・既知事例の統合検証に合格。同一原本から再生成した17ファイルはバイト単位で一致した。実行結果と生成物indexのハッシュは[validation.json](validation.json)に保存した。

## 原資料の版

Frame Data Explorerの版付き原資料は、既存アプリの固定ハッシュと照合した。Motion Values・戦灰適合表・Misc Effects・Build Planner・Scaling Dataの5参考シートは既存manifestから更新されていたため、別ハッシュの現行取得物として記録した。更新前と同一内容とは扱わない。補正曲線・属性補正や原資料にない効果のシート補完には、`reference_sheet_snapshot_not_verified_as_1.17_raw`の版範囲を付ける。

[HKS固定コミット](https://github.com/soulsmods/EldenRingHKS/commit/d88d6441f5fccfdd6a5fd10d493309b680181897)の説明には1.17対応と明記されるが、ファイルヘッダーの最終更新表記は1.15.1のまま。両方を記録し、コミュニティ編集版の入力ヒントとして使う。ゲーム本体の完全な入力選択処理とは認定しない。

配信サイトが使用する全TAEのサンプルURLは404だった。代替の[アニメーション資料リポジトリ](https://github.com/EldenRingDatabase/er-animation-data-diff/commit/d26d510738cde477eb27275d803f68b4f2c7b997)は1.14のため、1.17の原資料として混ぜていない。戦技ダメージ説明文書には1.04.1の記載があり、式の調査用資料としてのみ保存し、古い数値例は採用しなかった。

[公式更新情報](https://www.eldenring.jp/newsdetail/news_detail_260908_1.html)の版は1.17.1。今回の固定1.17資料との差分は未検証であり、1.17.1対応済みとは表示しない。

## 成果物と使用手順

保存先：`data/elden-ring-skills/all/`。GitHubには全17生成ファイルを完全復元できる`packed/`と、台帳CSV・監査・出典等を保存する。約79MBの展開JSONを重複してコミットせず、復元後は同じindexのSHA-256で検査できる。第1弾の対象も全件データに含む。

GitHubから取得した後の復元はPython標準ライブラリだけで実行できる。分割片・アーカイブ・各ファイルのハッシュを検査し、異なる既存ファイルがあれば上書きせず停止する。

```sh
python tools/elden-ring/skills/snapshot.py unpack
python tools/elden-ring/skills/verify.py
```

公開用の圧縮・復元処理は3追加テストで確認した。全19テストに合格し、圧縮データから復元した全件資料も統合検証に合格した。

| ファイル | 用途 |
|---|---|
| `coverage.csv` / `skills.json` | 全278行の台帳・FP・可用性・状態・阻害理由 |
| `actions.json` / `animations.json` | 行動候補、判定窓、入力未解決、原イベント |
| `attack-variants.json` / `parameters.json` | 加工参照と原行の接続、係数、弾/効果/補正のグラフ |
| `weapon-variants.json` / `ammo-parameters.json` / `compatibility.json` | 武器派生・弾薬・装着候補。戦灰ごとの例外は追加確認が必要 |
| `measurement-cases.json` | 実機測定の空テンプレート。推奨武器は候補で、入力条件も未確定 |
| `missing-references.json` / `issues.json` / `audit.json` | 欠落・影響範囲・件数・版の制約 |
| `metadata.json` / `source-manifest.json` / `index.json` | 単位・取り込み契約・出典・ファイルSHA-256 |
| `payload.json` | 実装用のgzip-base64包装。測定予定・監査/問題一覧は別ファイル |

Python 3とopenpyxlを使う。原本はリポジトリ外の`/workspace/elden-ring-skill-sources/1.17/`にある。再取得時はlockのハッシュが一致しなければ停止する。参考シートが更新されて古いスナップショットを復元できない場合は、新版として別管理する。

```sh
python tools/elden-ring/skills/collect.py --dest /workspace/elden-ring-skill-sources/1.17 --lock data/elden-ring-skills/all/source-manifest.json
python tools/elden-ring/skills/all.py --sources /workspace/elden-ring-skill-sources/1.17
python -m unittest discover -s tools/elden-ring/skills -p 'test_*.py'
python tools/elden-ring/skills/verify.py
```

取り込み時は包装の`sha256`と`raw_bytes`を検査する。JSONの`null`を0に変換しない。MVは100で倍率1。アニメーション資料の表示は30資料フレーム/秒だが、実行周期は未確定。`FinalDamageRateParam`はPvP用で、PvEに流用しない。`candidate_refs`や複数弾を全部足さず、武器・入力・命中条件を確定する。バフ候補、強化の効果IDオフセット、両手補正フラグも値だけで意味を確定しない。

アプリHTML・計算エンジンはこの収集で変更していない。GitHubへの反映対象は正規化した収集成果・コード・検証記録。原資料の再配布条件未確認という状態を維持し、原本は公開用の圧縮データに含めない。
