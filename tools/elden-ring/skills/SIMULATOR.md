# 戦技シミュレータの条件

収集済み1.17スナップショットを使い、武器ARから計算できる攻撃成分をシミュレートする。実機測定や最終式の全件検証を済ませたデータではない。収集台帳の `simulator_ready: false` は変更しない。

267候補を検索でき、1,225資料動作を収録する。171候補に少なくとも1つの武器攻撃成分モデルがある。171戦技すべての全動作・全段を計算できるという意味ではない。画面の計算対象は「選択した資料動作の、選択した各判定が1回命中する」という条件。

## 計算

`compile-runtime.mjs` は元資料のSHA-256とサイズを照合し、武器ごとの攻撃参照を解決する。同一判定の完全一致エイリアスは1つだけ採用する。異なる攻撃候補・親子弾を勝手に合算しない。

モデルに採用するのは、元パラメータと生成表の属性別MV・固定値が一致し、攻撃参照が解決し、弾参照がなく、固定値が0で、独自補正・特殊攻撃処理・未確認の両手補正がない成分に限る。

1. ビルドの装備補正後能力値、武器・派生、強化、片手／両手から属性別ARを計算する。
2. 各判定の属性別MVをARに掛ける。影樹の加護・手動攻撃力倍率は防御前に掛ける。
3. 選択敵の防御・カット率を属性・判定ごとに適用してから合計する。物理属性も判定ごとに使う。

未計算の判定が残る場合、全体合計とFP効率を表示せず、計算できた成分の小計と理由を表示する。判定を外せば選択した成分だけの仮定を試せるが、全判定を選んでいない場合のFP効率は出さない。バフ専用戦技や未対応の攻撃を0ダメージとして扱わない。

月隠は刀身の特殊攻撃処理と親子弾の接続・独自式が未検証で、ダメージ合計は未計算。猛獅子斬りの追撃は未確認処理のある判定を除いた成分のみ試算できる。二連斬りなどの対応成分は判定ごとに防御を適用して合算する。

## 動作・FP・適合

居合、構え、獅子斬り、貫通突き、月隠、猛獅子斬りの一部動作は入力ラベルと基礎FPを対応付けた条件モデル。構えR1/R2、始動と追撃を分離する。残りFP0の枝は残り0を仮定するもので、残り1以上のFP不足時の消費・挙動を再現しない。実機入力の対応付けは未測定。

それ以外は資料の動作名を表示し、入力ごとの消費FPは未計算のままにする。利用者が仮定FPを指定した場合だけ効率を計算し、「仮定」と表示する。元パラメータのFP -1は不明扱い。装備によるFP軽減・追加入力を含むコンボ全体のFPは自動適用しない。

武器の既定戦技、参考適合表、武器の戦灰変更可否を照合する。参考表が欠くDLCなどは原戦灰のカテゴリ・派生フラグと当該武器の動作資料が揃う場合に候補とし、画面で「個別例外は未確認」と表示する。完全な装着可否を保証しない。

追加効果は候補の原値を閲覧できるだけで、発動・消費・重複を確認して自動適用したことにはならない。状態異常、爆発・独自弾、固有能力値補正、ヒット数の距離依存、部位・カウンター・PvP、周期・ヒットストップ・戦技DPSは未対応。資料フレームはDPSに変換しない。1.17.1差分と実機の最終ダメージは未検証。

## 保存・生成・検証

戦技ID、武器派生、動作、選択判定、仮定FPは既存のビルドJSONに `skillSimulation` として保存する。旧ビルドは既定選択に移行し、自動保存・名前付き保存・共有URL・取り消しに対応する。

```bash
# 収集スナップショットから再生成。未展開ならsnapshot.pyが復元する。
node tools/elden-ring/skills/compile-runtime.mjs
node tools/build-elden-ring.mjs
node tools/test-elden-ring-skills.cjs
node tools/test-elden-ring-skills-ui.cjs
```

圧縮ランタイムは `data/elden-ring-skills/runtime/manifest.json` と7個のbase64パーツに保存する。通常のHTMLビルドはこの小さな成果物だけを読み、パーツ・展開後データ・元スナップショット・武器データのハッシュを照合する。大型原本の展開やPython・ネットワーク取得は不要。生成HTMLにすべて内蔵し、アプリ実行時にも追加データを取得しない。

数値テストは既知MV/FP定数、各段・属性の防御、能力不足、強化、持ち方、FP0、不適合、DLC候補、未対応を含む小計、独自弾の非合算、手動FP、旧保存互換を確認する。UIテストはR1/R2・FP0、判定選択、未計算の表示、能力変更、保存・取り消し・共有、390/1440px、通信遮断時の単一HTML起動を確認する。これは実機精度の保証ではない。
